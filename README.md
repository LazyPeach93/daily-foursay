# 每日四说

每天练习「跟、背、诵、说」，让表达更清晰、更自然。

这是一个中文口语表达训练资料库。每份资料提供一组练习，四项可分别选材，内容可以涉及生活、工作、历史、文化、科学和社会观察。现阶段以更新资料为主，无需安装软件。

## 四步怎么练

1. **跟**：跟着音频或视频说话，留意吐字、语速和节奏。
2. **背**：理解一段文字，尝试脱稿背诵；可以先分句练习。
3. **诵**：出声朗读一段文字，注意停顿、轻重和语气。
4. **说**：围绕一道题，用自己的话表达理解；可以录音转写，再请 AI 反馈并重新说一次。

「跟、背、诵」各练约 5 分钟，「说」可根据自己的时间调整。先完成练习，再逐渐增加难度。

## 开始练习

1. 在 [每日训练](daily/) 中按日期选择一份资料，或从 [第一天的练习](daily/2026/11/2026-11-07.md) 开始。
2. 依次完成四步；跟读优先收听资料中链接的真人播报。
3. 用 AI 复盘「说」的内容，选择一条建议重新练习。

## 方法与素材

「跟、背、诵」参考赵玉平老师分享的口才训练方法；「说」是本项目增加的开放表达练习，用于练习组织观点和用自己的话表达。具体时间只是练习建议，效果因人而异。

素材会尽量注明来源与使用方式。引用或使用音视频、文章时，请遵守原作者及平台的授权要求。练习时可根据个人情况选择适合的材料。
